# Runtime System - Loading and Executing Compiled Artifacts

This reference covers TVM's runtime system, which provides the minimal infrastructure needed to load, execute, and interact with compiled ML models. The runtime is designed to be lightweight, portable, and language-agnostic.

---

## 20.1 Runtime Overview

TVM's runtime system is the interface between compiled artifacts (generated by `relax.build` or `tvm.build`) and the user's application. It provides:

- **Module loading**: Load compiled models from disk or memory.
- **Function execution**: Call compiled functions with typed arguments.
- **Device management**: Allocate memory, transfer data between devices.
- **Tensor operations**: Create, manipulate, and convert NDArray objects.
- **Cross-language support**: C API foundation enables Python, C++, Rust, Go, Java, JavaScript bindings.

The runtime is intentionally minimal -- it does not depend on the compiler. This separation means the deployment environment only needs the lightweight runtime, not the full TVM compilation stack.

**Deployment footprint**: The runtime library is approximately 2-5 MB, compared to the full TVM stack at 100+ MB. This makes it suitable for embedded and mobile deployment.

## 20.2 Language Bindings

### 20.2.1 C API Foundation

All TVM runtime functionality is built on a C API (`tvm/runtime/c_runtime_api.h`). Every higher-level language binding wraps this C API.

```c
#include <tvm/runtime/c_runtime_api.h>

// Initialize TVM runtime
int TVMInitializeGlobal();

// Module operations
int TVMModLoadFromFile(const char* file_name,
                       const char* format,
                       TVMModuleHandle* out);

int TVMModGetFunction(TVMModuleHandle mod,
                      const char* name,
                      TVMFunctionHandle* out);

// Function invocation
int TVMFuncCall(TVMFunctionHandle func,
                TVMValue* args,
                int* arg_type_codes,
                int num_args,
                TVMValue* ret_val,
                int* ret_type_code);

// NDArray operations
int TVMArrayAlloc(const tvm_index_t* shape,
                  int ndim,
                  int dtype_code,
                  int dtype_bits,
                  int dtype_lanes,
                  int device_type,
                  int device_id,
                  TVMArrayHandle* out);

int TVMArrayFree(TVMArrayHandle handle);

int TVMArrayCopyFromTo(TVMArrayHandle from,
                       TVMArrayHandle to);
```

### 20.2.2 Python Binding

Python is the primary interface for TVM development:

```python
import tvm
from tvm import runtime
from tvm.runtime import Module, PackedFunc, NDArray

# Load a compiled module
mod = runtime.load_module("model.so")

# Get a function
func = mod["main"]

# Create input tensors
x = tvm.nd.array(np.random.randn(128, 128).astype("float32"), device=tvm.cuda(0))

# Execute
result = func(x)
```

### 20.2.3 C++ Binding

```cpp
#include <tvm/runtime/module.h>
#include <tvm/runtime/packed_func.h>
#include <tvm/runtime/ndarray.h>

// Load module
tvm::runtime::Module mod = tvm::runtime::Module::LoadFromFile("model.so");

// Get function
tvm::runtime::PackedFunc func = mod.GetFunction("main");

// Create input
DLTensor* input = ...;  // or tvm::runtime::NDArray

// Execute
tvm::runtime::TVMRetValue result = func(input);
```

### 20.2.4 Rust Binding

```rust
use tvm_runtime::{Module, NDArray, Device};

// Load module
let mod = Module::load("model.so").unwrap();

// Get function
let func = mod.get_function("main").unwrap();

// Create input

// Execute
let result = func.invoke(vec![input.into()]).unwrap();
```

## 20.3 runtime.Object

### 20.3.1 Object Base Class

`runtime.Object` is the reference-counted base class for all TVM runtime objects. It provides:
- **Reference counting**: Automatic memory management via `std::shared_ptr` semantics.
- **Runtime type identification**: Each object has a type index for safe downcasting.
- **Deferred destructors**: Objects can be registered for cleanup at context exit.

```cpp
// C++ Object base class
class Object {
public:
    // Type index for RTTI
    uint32_t type_index() const;

    // Reference count
    int use_count() const;

    // Unique type key
    static constexpr const char* _type_key = "runtime.Object";

    // Check if object is an instance of a type
    bool IsInstance(uint32_t type_index) const;
};
```

### 20.3.2 Runtime Type Checking

```python
import tvm
from tvm import runtime

# Every Object has a type_key
obj = tvm.runtime.String("hello")
print(obj.type_key)  # "runtime.String"

# Type checking
print(isinstance(obj, tvm.runtime.String))  # True (if supported)
print(isinstance(obj, tvm.runtime.Object))  # True
```

### 20.3.3 Downcasting

```python
# Safe downcasting using type_index
obj = ...  # some Object
if isinstance(obj, tvm.runtime.Array):
    arr = obj  # safely downcast
    for item in arr:
        print(item)
```

### 20.3.4 Built-in Data Structures

**Array**: Reference-counted container similar to Python list.

```python
from tvm.runtime import Array

# Create array
arr = Array([1, 2, 3, 4, 5])

# Access elements
print(arr[0])     # 1
print(len(arr))   # 5

# Iterate
for item in arr:
    print(item)

# Create with Objects
arr_str = Array(["hello", "world"])  # Array of runtime.String
arr_target = Array([target1, target2])  # Array of Target objects
```

**Map**: Reference-counted dictionary.

```python
from tvm.runtime import Map, String

# Create map
m = Map({
    "key1": "value1",
    "key2": 42,
    "key3": tvm.target.Target("cuda"),
})

# Access
print(m["key1"])  # "value1"

# Iterate
for key, value in m.items():
    print(f"{key}: {value}")

# Check membership
if "key1" in m:
    print("found")
```

**String**: Reference-counted string type.

```python
from tvm.runtime import String

s = String("hello")
print(len(s))      # 5
print(str(s))      # "hello"
print(s == "hello")  # True
```

## 20.4 PackedFunc

### 20.4.1 Overview

`PackedFunc` is TVM's universal function interface. It is a type-erased, dynamically-typed callable that can accept and return a wide range of argument types. PackedFunc is the backbone of all runtime function calls.

### 20.4.2 Supported Argument Types

PackedFunc can handle the following types without explicit conversion:

| Type | Description | Type Code |
|---|---|---|
| `int` | 32-bit or 64-bit integer | `kDLInt` |
| `float` | 32-bit or 64-bit float | `kDLFloat` |
| `bool` | Boolean | `kDLInt` (1-bit) |
| `str` | Python string -> `runtime.String` | `kTVMStr` |
| `bytes` | Byte string | `kTVMBytes` |
| `DLDevice` | Device descriptor | `kDLDevice` |
| `DLDataType` | Data type descriptor | `kTVMDataType` |
| `NDArray` | Tensor / DLTensor | `kTVMNDArrayHandle` |
| `Module` | Runtime module | `kTVMModuleHandle` |
| `PackedFunc` | Nested function | `kTVMPackedFuncHandle` |
| `Object` | Any TVM Object subclass | `kTVMObjectHandle` |
| `None` | Null value | `kTVMNullptr` |

### 20.4.3 Creating PackedFunc

**From Python function**:
```python
from tvm.runtime import PackedFunc

def my_func(x, y):
    return x + y

# TVM automatically wraps Python functions as PackedFunc
# when registering or passing to TVM APIs
```

**From C++ function**:
```cpp
#include <tvm/runtime/packed_func.h>

// Register a C++ function as PackedFunc
TVM_REGISTER_GLOBAL("my_add")
.set_body([](tvm::runtime::TVMArgs args, tvm::runtime::TVMRetValue* rv) {
    int a = args[0];
    int b = args[1];
    *rv = a + b;
});
```

**Accessing registered functions**:
```python
import tvm

# Get a globally registered PackedFunc
my_add = tvm.get_global_func("my_add")
result = my_add(3, 4)  # 7
```

### 20.4.4 PackedFunc in Code Generation

When TVM compiles a function, the generated code is wrapped in a PackedFunc:

```python
import tvm
from tvm import tir
from tvm.script import ir as I, tirx as T

@I.ir_module
class MyModule:
    @T.prim_func
    def add(A: T.Buffer((128,), "float32"), B: T.Buffer((128,), "float32")) -> None:
        for i in range(128):
            with T.sblock("B"):
                vi = T.axis.spatial(128, i)
                B[vi] = B[vi] + A[vi]

# Build to get a runtime module
rt_mod = tvm.build(MyModule, target="llvm")

# Get the compiled function as PackedFunc
add_func = rt_mod["add"]
print(type(add_func))  # <class 'tvm.runtime.packed_func.PackedFunc'>
```

### 20.4.5 PackedFunc Calling Convention

When a PackedFunc is called, arguments are packed into a `TVMArgs` structure:

```cpp
// C++ calling convention
class TVMArgs {
public:
    // Access arguments by index
    int num_args() const;

    // Typed access with automatic conversion
    template<typename T>
    T operator[](int index) const;

    // Raw access
    TVMValue values_[kMaxArgs];
    int type_codes_[kMaxArgs];
};

// Return value
class TVMRetValue {
public:
    // Set return value
    template<typename T>
    void operator=(T value);

    // Get return value
    template<typename T>
    operator T() const;
};
```

## 20.5 runtime.Module

### 20.5.1 Overview

`runtime.Module` encapsulates a compilation result -- one or more compiled functions along with any necessary metadata, libraries, or device-specific code. Modules are the primary unit of deployment.

### 20.5.2 Module Lifecycle

```
Build/Compile
     |
     v
runtime.Module
     |
     |--- GetFunction(name) -> PackedFunc
     |--- import_module(other_module)
     |--- export_library(path)
     |
     v
Load from file
     |
     v
runtime.Module (ready for execution)
```

### 20.5.3 Getting Functions from a Module

```python
import tvm

# Load or build a module
rt_mod = tvm.build(mod, target="llvm")

# Get a function by name
func = rt_mod["main"]       # Returns PackedFunc
func = rt_mod.get_function("main")  # Equivalent

# Check if function exists
try:
    func = rt_mod["nonexistent"]
except AttributeError:
    print("Function not found")
```

### 20.5.4 Module Composition

Modules can be composed hierarchically -- a host module can import device modules:

```python
import tvm
from tvm.target import Target

# Build with CUDA target (creates host + device modules)
target = Target("cuda", host="llvm")
rt_mod = tvm.build(mod, target=target)

# The runtime module internally contains:
# - Host module (LLVM compiled, manages execution)
# - CUDA module (kernel functions)

# Import additional modules
external_mod = tvm.runtime.load_module("external_kernels.so")
rt_mod.import_module(external_mod)
```

### 20.5.5 Export and Import

```python
import tvm

# Export to shared library
rt_mod = tvm.build(mod, target="llvm")
rt_mod.export_library("my_model.so")

# Export with format specification
rt_mod.export_library("my_model.tar", format="tar")

# Load from file
loaded_mod = tvm.runtime.load_module("my_model.so")

# Load with explicit format
loaded_mod = tvm.runtime.load_module("my_model.tar", fmt="tar")
```

### 20.5.6 Module Types

TVM supports multiple module formats:

| Format | Extension | Description |
|---|---|---|
| Shared library | `.so`, `.dll`, `.dylib` | Native shared library |
| Flatbuffer | `.ro` | Relax executable (Relax VM bytecode) |
| Tar archive | `.tar` | Archive containing multiple files |
| System lib | (none) | Linked into the process at compile time |

```python
# System library: compile functions into the process
# This is used for microcontrollers and bare-metal deployment
rt_mod.export_library("my_model.o", system_lib=True)
```

## 20.6 Device API

### 20.6.1 Device Management

TVM uses DLDevice to represent compute devices:

```python
import tvm

# Create device handles
cpu = tvm.cpu(0)          # CPU device 0
cuda = tvm.cuda(0)        # CUDA device 0
cuda1 = tvm.cuda(1)       # CUDA device 1
rocm = tvm.rocm(0)        # ROCm device 0
metal = tvm.metal(0)      # Metal device 0
cl = tvm.opencl(0)        # OpenCL device 0
vulkan = tvm.vulkan(0)    # Vulkan device 0
ext = tvm.ext_dev(0)      # External device

# Device attributes
print(cuda.device_type)   # 2 (kDLCUDA)
print(cuda.device_id)     # 0
print(cuda.exist)          # True if device is available
print(cuda.max_threads_per_block)  # GPU-specific
print(cuda.warp_size)      # 32 for NVIDIA, 64 for AMD
print(cuda.total_memory)   # Total GPU memory in bytes
print(cuda.compute_version) # "8.0" for A100
```

### 20.6.2 Memory Allocation

```python
import tvm
import numpy as np

dev = tvm.cuda(0)

# Allocate uninitialized NDArray
x = tvm.nd.empty((128, 128), dtype="float32", device=dev)

# Allocate from numpy array (copies to device)
data_np = np.random.randn(128, 128).astype("float32")
x = tvm.nd.array(data_np, device=dev)

# Allocate on CPU
y = tvm.nd.array(np.zeros((128, 128), dtype="float32"), device=tvm.cpu(0))
```

### 20.6.3 Data Transfer

```python
import tvm
import numpy as np

# Host -> Device
data_cpu = tvm.nd.array(np.random.randn(128, 128).astype("float32"), device=tvm.cpu(0))
data_gpu = tvm.nd.empty((128, 128), dtype="float32", device=tvm.cuda(0))
data_gpu.copyfrom(data_cpu)

# Device -> Host
result_cpu = data_gpu.copyto(tvm.nd.empty((128, 128), dtype="float32", device=tvm.cpu(0)))

# Device -> Device (GPU 0 to GPU 1)
data_gpu1 = tvm.nd.empty((128, 128), dtype="float32", device=tvm.cuda(1))
data_gpu1.copyfrom(data_gpu)

# Convenience: numpy() pulls data back to host as numpy array
result_np = data_gpu.numpy()
```

### 20.6.4 Stream Management

GPU devices support asynchronous execution via streams:

```python
import tvm

dev = tvm.cuda(0)

# Create a stream
stream = tvm.cuda.stream(dev.device_id)

# Set current stream
with stream:
    # Operations in this context use the specified stream
    result = compiled_func(input_tensor)

# Synchronize stream
stream.sync()

# Synchronize device
tvm.cuda(0).sync()
```

```cpp

class DeviceAPI {
public:
    // Allocate memory

                                size_t nbytes,

    // Free memory

    // Copy data between devices

                                DLDataType type_hint,

    // Stream management
    virtual void CreateStream(Device dev, TVMStreamHandle* out) = 0;
    virtual void FreeStream(Device dev, TVMStreamHandle stream) = 0;
    virtual void SyncStream(Device dev, TVMStreamHandle stream) = 0;

    // Device synchronization
    virtual void StreamSync(Device dev, TVMStreamHandle stream) = 0;

```

## 20.7 Tensor Operations (NDArray)

### 20.7.1 NDArray Overview

`tvm.runtime.NDArray` (also called `tvm.nd.array`) wraps a `DLTensor` and provides managed tensor storage with automatic device-aware memory management.

```python
import tvm
import numpy as np

# Create NDArray from numpy
x = tvm.nd.array(np.array([1, 2, 3, 4], dtype="float32"))
print(x.shape)      # (4,)
print(x.dtype)      # float32
print(x.device)     # cpu(0)

# Create on specific device
x_gpu = tvm.nd.array(np.array([1, 2, 3, 4], dtype="float32"), device=tvm.cuda(0))

# Create empty array
y = tvm.nd.empty((128, 128), dtype="float32", device=tvm.cuda(0))
```

### 20.7.2 NDArray Properties

```python
x = tvm.nd.array(np.zeros((3, 4), dtype="float32"))

x.shape          # (3, 4)
x.dtype          # float32
x.device         # cpu(0)
x.ndim           # 2
x.size           # 12 (total elements)
x.nbytes         # 48 (total bytes)
```

### 20.7.3 NDArray Data Access

```python
# Convert to numpy (copies from device to host)
arr_np = x.numpy()
print(type(arr_np))  # <class 'numpy.ndarray'>

# Modify via numpy and copy back
arr_np[0, 0] = 42.0
x.copyfrom(arr_np)

# For GPU arrays, numpy() implicitly transfers data
x_gpu = tvm.nd.array(np.ones((3, 4), dtype="float32"), device=tvm.cuda(0))
arr = x_gpu.numpy()  # Device -> Host copy
```

### 20.7.4 DLPack Integration

DLPack provides a standard tensor exchange format for zero-copy interoperability between frameworks (PyTorch, TensorFlow, MXNet, NumPy, etc.).

```python
import tvm
import numpy as np

# TVM NDArray -> DLPack
x = tvm.nd.array(np.random.randn(128, 128).astype("float32"), device=tvm.cuda(0))
dlpack_cap = x.to_dlpack()  # Returns a PyCapsule containing DLTensor

# DLPack -> TVM NDArray
x2 = tvm.nd.from_dlpack(dlpack_cap)

# Interop with PyTorch
import torch
torch_tensor = torch.from_dlpack(x.to_dlpack())  # Zero-copy view

# Interop from PyTorch to TVM
torch_tensor = torch.randn(128, 128, device="cuda")
tvm_array = tvm.nd.from_dlpack(torch_tensor.__dlpack__())  # Zero-copy view
```

### 20.7.5 DLTensor Structure

The underlying C structure:

```c
typedef struct DLTensor {
    void* data;              // Data pointer
    DLDevice device;         // Device (type + id)
    int ndim;                // Number of dimensions
    DLDataType dtype;        // Data type (code, bits, lanes)
    int64_t* shape;          // Shape array (length = ndim)
    int64_t* strides;        // Stride array (NULL for compact)
    uint64_t byte_offset;    // Byte offset from data pointer
} DLTensor;

typedef struct DLDevice {
    DLDeviceType device_type;  // kDLCPU, kDLCUDA, etc.
    int device_id;             // Device index
} DLDevice;

typedef struct DLDataType {
    uint8_t code;     // Type code: kDLInt=0, kDLUInt=1, kDLFloat=2, kDLBfloat=4
    uint8_t bits;     // Bits per element: 8, 16, 32, 64
    uint16_t lanes;   // SIMD lanes (1 for scalar)
} DLDataType;
```

## 20.8 RPC Runtime

### 20.8.1 Overview

TVM's RPC (Remote Procedure Call) runtime enables:
- **Remote execution**: Run compiled code on a remote device.
- **Cross-compilation**: Compile on one machine, execute on another.
- **Remote benchmarking**: Measure performance on target hardware remotely.
- **Debugging**: Test on devices that are not locally available.

### 20.8.2 RPC Server Setup

Start an RPC server on the target machine:

```bash
# On the target machine (e.g., Android device, remote GPU server)
python -m tvm.exec.rpc_server --host 0.0.0.0 --port 9090

# With specific tracker configuration
python -m tvm.exec.rpc_server \
    --host 0.0.0.0 \
    --port 9090 \
    --tracker 192.168.1.100:9190 \
    --key "nvidia-a100"
```

### 20.8.3 RPC Client Usage

```python
import tvm
from tvm import rpc

# Connect to RPC server
remote = rpc.connect("192.168.1.200", 9090)

# Upload compiled module
remote.upload("my_model.so")

# Load module on remote
remote_mod = remote.load_module("my_model.so")

# Create remote NDArray
dev = remote.cuda(0)
x = tvm.nd.array(np.random.randn(128, 128).astype("float32"), device=dev)

# Execute on remote
func = remote_mod["main"]
result = func(x)

# Download result
result_np = result.numpy()  # Transfers from remote device to local
```

### 20.8.4 RPC Tracker

For managing multiple remote devices:

```bash
# Start tracker
python -m tvm.exec.rpc_tracker --host 0.0.0.0 --port 9190
```

```python
from tvm import rpc

# Connect via tracker
tracker = rpc.connect_tracker("192.168.1.100", 9190)

# Request a specific device
remote = tracker.request("nvidia-a100", priority=0)

# List available devices
summary = tracker.summary()
print(summary)
```

### 20.8.5 RPC for Auto-Tuning

```python
from tvm import rpc, autotvm

# Configure tuning to use remote device
measure_option = autotvm.measure_option(
    builder=autotvm.LocalBuilder(),
    runner=autotvm.RPCRunner(
        "nvidia-a100",              # Device key
        host="192.168.1.100",       # Tracker host
        port=9190,                  # Tracker port
        number=5,                   # Number of runs per config
        timeout=10,                 # Timeout per run
    ),
)

# Tune with remote execution
tuner = autotvm.tuner.XGBTuner(tuning_task)
tuner.tune(
    n_trial=100,
    measure_option=measure_option,
)
```

```python
import tvm
```

```python
dev = tvm.rocm(0)
```

**Metal** (`runtime/metal/`):

```python
dev = tvm.metal(0)
```

### 20.9.3 Relax Virtual Machine (`runtime/vm/`)

The Relax VM executes Relax bytecode directly, providing efficient graph-level execution:

```python
import tvm
from tvm import relax

# Build Relax module to VM executable
exec = relax.build(mod, target="nvidia/nvidia-a100")

# Create VM instance
vm = relax.VirtualMachine(exec, tvm.cuda(0))

# Execute
result = vm["main"](input_tensor)

# Profiling
vm.save_executable("model.ro")  # Save bytecode
```

**VM bytecode operations**:
- `Call`: Call a PackedFunc or TIR function.
- `Ret`: Return a value.
- `Goto`: Unconditional jump.
- `If`: Conditional branch.
- `LoadConst`: Load a constant.
- `AllocTensor`: Allocate a tensor.
- `AllocStorage`: Allocate storage (for paged memory).

### 20.9.4 Disco Distributed Runtime (`runtime/disco/`)

Disco enables distributed inference and training across multiple devices:

```python
from tvm.runtime import disco
```

## 20.10 Global Function Registry

### 20.10.1 Registering Global Functions

TVM maintains a global registry of PackedFunc objects that can be accessed by name:

```cpp
// C++ registration
TVM_REGISTER_GLOBAL("runtime.MyAdd")
.set_body([](tvm::runtime::TVMArgs args, tvm::runtime::TVMRetValue* rv) {
    int a = args[0];
    int b = args[1];
    *rv = a + b;
});

// C++ registration with typed interface
TVM_REGISTER_GLOBAL("runtime.TypedAdd")
.set_body_typed([](int a, int b) -> int {
    return a + b;
});
```

```python
# Python registration
@tvm.register_func("runtime.PyAdd")
def py_add(a, b):
    return a + b
```

## 20.11 Memory Management

### 20.11.1 NDArray Memory Lifecycle

```python
# NDArray uses reference counting
x = tvm.nd.array(np.ones((128,), "float32"), device=tvm.cuda(0))

# Reference count increases when assigned
y = x  # ref count = 2

# Reference count decreases when variables go out of scope
del y  # ref count = 1
del x  # ref count = 0, memory freed
```

### 20.11.2 VM Memory Management

The Relax VM supports configurable memory management:

```python
# The VM memory manager allocates storage pools
# and reuses memory across function calls
vm = relax.VirtualMachine(exec, dev)

# Paged memory allocation (for LLM inference)
# The VM can use a paged allocator for efficient KV cache management
```

### 20.11.3 Allocator Types

The VM supports multiple allocator strategies:

```python
# Naive allocator: allocates new memory for each tensor
# Pooled allocator: reuses freed memory from a pool
```

## 20.13 Practical Examples

### 20.13.1 Complete Build-Deploy-Execute Workflow

```python
import tvm
import numpy as np
from tvm import relax
from tvm.target import Target
from tvm.script import ir as I, tirx as T, relax as R

# Step 1: Define the model
@I.ir_module
class AddModel:
    @T.prim_func
    def add_kernel(
        A: T.Buffer((128,), "float32"),
        B: T.Buffer((128,), "float32"),
        C: T.Buffer((128,), "float32"),
    ) -> None:
        T.func_attr({"global_symbol": "add_kernel", "tir.noalias": True})
        for i in range(128):
            with T.sblock("C"):
                vi = T.axis.spatial(128, i)
                C[vi] = A[vi] + B[vi]

    @R.function
    def main(
        x: R.Tensor((128,), "float32"),
        y: R.Tensor((128,), "float32"),
    ) -> R.Tensor((128,), "float32"):
        with R.dataflow():
            lv = R.call_tir(
                AddModel.add_kernel,
                (x, y),
                out_sinfo=R.Tensor((128,), "float32"),
            )
            R.output(lv)
        return lv

# Step 2: Build
target = Target("llvm")
exec_mod = relax.build(AddModel, target=target)

# Step 3: Export
exec_mod.export_library("add_model.so")

# Step 4: Deploy (simulated in same process)
loaded_mod = tvm.runtime.load_module("add_model.so")
vm = relax.VirtualMachine(loaded_mod, tvm.cpu(0))

# Step 5: Execute
x_np = np.random.randn(128).astype("float32")
y_np = np.random.randn(128).astype("float32")
x_tvm = tvm.nd.array(x_np)
y_tvm = tvm.nd.array(y_np)
result = vm["main"](x_tvm, y_tvm)

# Step 6: Verify
np.testing.assert_allclose(result.numpy(), x_np + y_np, rtol=1e-6)
print("Passed!")
```

### 20.13.3 Integration with PyTorch via DLPack

```python
import torch
import tvm
import numpy as np

# Compile model for CUDA
# ... build steps ...
exec_mod = relax.build(mod, target="nvidia/nvidia-a100")
exec_mod.export_library("model.so")

# Load in deployment
loaded = tvm.runtime.load_module("model.so")
vm = relax.VirtualMachine(loaded, tvm.cuda(0))

# Create PyTorch tensor on GPU
torch_input = torch.randn(1, 3, 224, 224, device="cuda", dtype=torch.float32)

# Zero-copy conversion to TVM NDArray via DLPack
tvm_input = tvm.nd.from_dlpack(torch_input.__dlpack__())

# Execute
result = vm["main"](tvm_input)

# Zero-copy back to PyTorch
torch_result = torch.from_dlpack(result.to_dlpack())
print(torch_result.shape)
```
